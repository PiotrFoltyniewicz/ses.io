# Scenariusze E2E

Miejsce na testy przeglądarkowe po uruchomieniu aplikacji.

Główny scenariusz: właściciel zakłada bazę → zaprasza członka → członek przyjmuje zaproszenie i zgłasza materiał → właściciel zatwierdza → członek pobiera opublikowaną wersję → zgłasza poprawkę → odrzucenie zachowuje poprzednią wersję.

Dodatkowo sprawdzić brak dostępu z konta spoza bazy i zachowanie po odebraniu członkostwa. Konta i dane testowe tworzyć niezależnie od danych użytkowników.
