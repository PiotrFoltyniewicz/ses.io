# Infrastruktura

Miejsce na przyszły Compose dla PostgreSQL, konfigurację prywatnego magazynu plików, lokalną pocztę i wdrożenie. Obecnie brak działającej konfiguracji.

Podczas uruchamiania fundamentu dodać `.env.example` z nazwami wymaganych zmiennych, bez sekretów. Rzeczywiste pliki i dane PostgreSQL przechowywać poza kodem źródłowym. Dokumentacja wdrożenia powinna obejmować migracje, HTTPS, backup metadanych i plików oraz odtworzenie.
